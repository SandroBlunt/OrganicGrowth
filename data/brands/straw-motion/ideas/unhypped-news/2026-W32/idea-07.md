## Angle
Most "AI builds your app" claims arrive as a demo video. xAI's Grok Build shipped with a playable one:
driver.grok.me is a game built through it that anyone can open right now. The output is not trapped in
the chat either, it exports to GitHub or publishes live. And Grok Build workflows now orchestrate up to
1,024 parallel agents from a plain-language description. The tension: the ceiling on producing work just
jumped to 1,024 simultaneous agents, while the ceiling on checking that work is still one human.

## Hook concept
Open on the clickable proof rather than the claim, a real game you can play that came out of a chat
prompt, then reveal the 1,024-parallel-agents number as the scale behind it. The surprise is the gap
between how much can now be produced and how much anyone can review. (Concept only, writer lands the
final line.)

## Suggested Recipe
News Carousel (7 slides). Card one can carry the playable demo, the middle cards the mechanics, and the
close the honest "who checks the output" question, which is a stronger swipe payoff than a feature list.

## Talking points
- Grok Build deploys a coding agent that creates functional interactive apps and games directly from a
  chat prompt (xAI's announcement).
- The result leaves the chat window: you can export it to GitHub or publish it live (xAI).
- driver.grok.me is a playable game built this way, referenced alongside the announcement. It is a demo
  you can click, not a recording of one.
- Grok Build workflows now support up to 1,024 parallel agents for complex task orchestration, described
  in plain language rather than configured in code (xAI's workflows post).
- What 1,024 parallel agents is actually for: splitting one large job into many small ones running at
  once. The interesting question nobody has answered is who reviews 1,024 outputs.
- Un-hyped read: "builds an app from a prompt" means a working prototype, not a maintained product. Treat
  it as the fastest way yet to find out whether an idea is worth building properly.
