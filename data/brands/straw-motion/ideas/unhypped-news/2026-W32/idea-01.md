# idea-01 — "AI got 80% cheaper this week without getting any smarter"

- **Brand:** straw-motion

- **Rides trend:** trend-02 — The frontier-model price war just got brutal
- **Fit Score:** 0.72

## Angle
Four labs made price-or-efficiency moves in the same week and almost none of them involved a smarter
model. OpenAI rewrote how GPT-5.6 Sol is served and cut Luna API pricing 80%, to $0.20 per million input
tokens. Anthropic shipped Claude Opus 5 that matches or beats Fable 5 on most benchmarks at the identical
$5 per million input tokens. Google's Gemini 3.6 Flash does the same work with 17% fewer tokens. The
tension: we're trained to watch for the next big brain, and the thing that actually changed this week was
the bill. Any project a builder shelved for cost reasons three months ago now has different math.

## Hook concept
Open on the $0.20 figure and the fact that the model behind it did not change at all, only the plumbing
that serves it. The surprise is that an 80% cut came from serving code, not a new release. (Concept only,
writer lands the final line.)

## Suggested Recipe
News Carousel (7 slides). Four labs with four numbers is a natural card-per-claim swipe, and the closing
card can carry the "re-price the thing you shelved" takeaway.

## Talking points
- OpenAI's own post says optimized serving code for GPT-5.6 Sol cut Luna API pricing by 80%, to $0.20 per
  million input tokens. The model did not change, the way it is served did.
- Anthropic's Claude Opus 5 matches or beats Fable 5 on most benchmarks at the identical $5 per million
  input tokens, so the same invoice now buys a better model (Anthropic's launch post).
- Google's Gemini 3.6 Flash uses 17% fewer tokens for the same work, which is a discount that arrives as
  smaller usage rather than a lower sticker price (Google's announcement).
- Google shipped two more tiers alongside it, a cheaper 3.5 Flash-Lite and a cybersecurity-tuned 3.5
  Flash Cyber, so one model is being split into cheaper, job-specific versions.
- The builder read: the feature you cut because "we can't run that on every customer" is worth pricing
  again this week before you redesign it.
- Honest catch: input price is one line on the bill. How many tokens you send, how much context you stuff
  in, and how often you retry still decide what you actually pay, so an 80% list cut is not an 80% cut on
  your invoice.
