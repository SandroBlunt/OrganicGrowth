# Cursor built its own GitHub, and the price of that convenience is where your code lives

- **Corroboration:** moderate. Four links, but only two are independent reporting (Cursor's own changelog and TechCrunch). AINews and TLDR AI are daily digests carrying the same item, so treat them as reach, not as a second opinion.

## Suggested Recipe
Both, per the Format. **News Carousel** rides the landlord-versus-tenant shift: hook on the assumption that broke, then what Origin is, then why TechCrunch says "frustration", then the lock-in catch. **News Short Script** carries the same spine with one plain line for "code hosting" and the switching-cost problem as its skeptic beat.

## Angle
The tension is about who owns the address your work lives at. For a decade the split was settled: you pick your editor, your code lives on GitHub, and the two are separate decisions. Cursor just collapsed them. Origin is Cursor's own code hosting, announced on Cursor's own changelog, and TechCrunch's headline says Cursor is "capitalizing on GitHub frustration". The contrast to ride: the AI editor people already keep open all day is now offering to keep the code too, and that is convenient right up until you want to leave.

## Hook Concept
The surprise is scope creep with a direction. Open on the thing everyone assumed was permanent, that your code lives on GitHub whatever editor you use, then name what Cursor shipped: its own hosting, on its own changelog, this week. The reframe is that the AI editor is quietly becoming the entire toolchain, and the bill for that arrives later. Concept only, the writer lands the final line.

## Talking Points
- Cursor announced it on its own changelog under "Origin code hosting" (cursor.com/changelog/origin-code-hosting). A first-party release note means this shipped, it is not a rumour or a waitlist.
- TechCrunch names the motive in its own headline: Cursor "capitalizes on GitHub frustration, launches rival hosting platform" (Aug 18). That word "frustration" is TechCrunch's read on why the timing works.
- Plain English for a beginner: code hosting is the shared folder a software team keeps its work in, plus the full history of every change anyone made. GitHub, owned by Microsoft, has been the default address for that for over a decade.
- Both developer daily digests on the Format's source list carried it: AINews by smol.ai (issue 26-08-17) and TLDR AI (Aug 18). Landing in both is a signal it registered with builders specifically.
- The builder read: your editor and your repository have always been two separate, reversible choices. If one company sells both, changing editors later stops being free.
- Straw Motion angle: this is the same consolidation pattern the Brand has covered before, where the tool that saves you an hour a day slowly becomes the tool you cannot leave. Name the pattern, not just the product.

## The Catch (mandatory skeptic beat)
This is day one of a hosting product going up against one that already holds everyone's continuous integration, issue history, integrations and muscle memory. TechCrunch's own framing is "frustration", not "migration": nobody in this evidence has actually moved a real team over. And the honest version of the pitch is that Cursor's advantage is not better hosting, it is that Cursor already has your editor. Convenience is the feature and the trap in the same sentence.
