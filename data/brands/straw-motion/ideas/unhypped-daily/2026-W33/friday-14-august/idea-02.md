# OpenAI's new Ultrafast mode runs GPT-5.6 Sol at 750 tokens per second — but does it think any better?

## Angle
OpenAI partnered with wafer-scale chipmaker Cerebras to make GPT-5.6 Sol spit out answers 14 times faster (750 tokens/sec), turning long multi-step agent loops into near-instant execution while the underlying intelligence remains identical.

## Hook Concept

## Talking Points
- OpenAI previewed Ultrafast mode, a new API service tier running GPT-5.6 Sol at up to 14x regular speed.
- The tier delivers up to 750 output tokens per second, powered by Cerebras wafer-scale engine hardware.
- The target use case is interactive voice agents, real-time code autocomplete, and multi-turn autonomous loops where latency was the primary bottleneck.
- The honest catch: 14x token speed means your agent finishes faster, not smarter. A flawed reasoning step or hallucination just arrives in milliseconds instead of seconds.
